# XDC_Node_Behind_CGNAT
Automatically monitors your XDC node peer count (Docker) and forces peer addition via peer.sh when it drops below 15. Includes ntfy.sh alerts, pause/restart controls, and systemd auto-start for Ubuntu 26.04.
